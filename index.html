Задача из трекера → документ для заказчика

Загрузите .doc-выгрузку задачи из Yandex Tracker — инструмент разберёт структуру, проверит обязательные разделы и соберёт аккуратный .docx. Файл никуда не отправляется (кроме API Claude — и то только если включите переписывание текста).

    3
    Настройки документа
    Необязательно — по умолчанию уже настроено разумно
    Ключ вводить не нужно. Эта страница — артефакт Claude: если открыть её прямо в Claude.ai (или по ссылке, которой поделились через кнопку «Опубликовать» на артефакте), запрос к Claude пройдёт через ваш собственный аккаунт claude.ai — без ключей и оплаты за API отдельно от подписки.

    Если этот файл скачан и открыт отдельно (не как артефакт Claude, например file:// или на своём сервере) — переписывание работать не будет, а остальные функции (разбор задачи и сборка .docx) продолжат работать как обычно.
    По умолчанию выбраны все разделы — снимите галочку с тех, что должны остаться как в системе.
    Агент сам определил, куда в документе они относятся — просто прикрепите файлы с компьютера.
